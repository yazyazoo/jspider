# Installation and distribution

JSpider is available in two ready-to-use forms. Neither public distribution
contains `config.local.json` or private credentials.

## Release ZIP

Download [jspider-v0.1.0.zip](https://github.com/yazyazoo/jspider/releases/download/v0.1.0/jspider-v0.1.0.zip)
from the [JSpider Releases page](https://github.com/yazyazoo/jspider/releases),
then:

1. Extract the ZIP to a permanent directory.
2. Copy `config.example.json` to `config.local.json` in that directory.
3. Enter the TaskFlow, TMDB, OMDb and optional Emby values.
4. Open the Chromium extensions page and enable Developer mode.
5. Choose **Load unpacked** and select the extracted directory containing
   `manifest.json`.

The files in the ZIP are at archive root, so no source build is required.

## Tracked dist directory

The repository contains a compiled
[dist/ directory](https://github.com/yazyazoo/jspider/tree/main/dist). After
cloning the repository, it can be loaded directly:

1. Create `dist/config.local.json` from `dist/config.example.json`.
2. Fill the local configuration.
3. Choose **Load unpacked** and select the repository’s `dist/` directory.

Do not select the repository root. `dist/config.local.json` is ignored even
though the remaining `dist/` files are tracked.

## Maintainer rule

`dist/` is generated by `npm run build` and committed together with the source
change that produced it. `release/` remains local and ignored; the
`jspider-v<version>.zip` file is published as a GitHub Release asset.
